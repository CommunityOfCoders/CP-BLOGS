# Contribution Guidelines

For now only contributions from CP Club Members will be accepted.

You have to follow the below steps

1. Make a fork of the repo.
2. Make your own branch.
3. Create an issue in the main repository using the template given.
4. Either you or someone solves the problem.
5. Problem Code must be clean, short, with no template sections. 
6. It is preferred to have comments for explanation and variables following a common case like Pascal case or Camel case.
7. Please don't use AI.
8. Once done you must simply add the solution link alongside the problem link in the respective md file.
9. For example: 
[CF 959 A - Mahmoud and Ehab and the even-odd game](https://codeforces.com/problemset/problem/959/A)  : [Solution Link](https://codeforces.com/contest/959/submission/387968974)
Like this.
10. **That must be the ONLY change you do in your fork. Before committing your change make sure to git pull from the main repo, to avoid merge conflicts.**
11. Make a PR after committing and mention the issue. Upon inspection the PR will be merged and the issue closed. Sometimes it may take some time, so please be patient.

Happy Coding!
