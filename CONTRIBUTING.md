# Contribution Guidelines

> For now only contributions from **CP Club Members** will be accepted.

You have to follow the below steps

1. **Fork** the repo.
2. Create your **own branch**.
3. Create an **issue** in the main repository using the given template.
4. Either you or someone else solves the problem.
5. Problem code must be **clean, short, with no template sections**.
6. Add comments for explanation, and name variables in a consistent case (PascalCase or camelCase).
7. **Please don't use AI.**
8. Once done, simply add the **solution link alongside the problem link** in the respective `.md` file.

   Example:

   ```md
   [CF 959 A - Mahmoud and Ehab and the even-odd game](https://codeforces.com/problemset/problem/959/A)  : [Solution Link](https://codeforces.com/contest/959/submission/387968974)
   ```

9. **That must be the ONLY change in your fork.** Before committing, run `git pull` from the main repo to avoid merge conflicts.
10. Make a **PR** after committing and mention the issue. After inspection the PR will be merged and the issue closed. It may take some time, so please be patient.

Happy Coding! 💻💚
